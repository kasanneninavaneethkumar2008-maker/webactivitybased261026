## Open and edit

Each website is in its own folder and has one matching `.html`, `.css`, and `.js` file. Open the HTML file in a browser to use it. To edit, right-click a file, choose **Open with → Notepad**, save, and refresh the browser. The files are plain HTML, CSS, and JavaScript and require no setup or build step. The sample order and booking interactions run in the browser and do not submit real payments or reservations.
